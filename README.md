# lume

Landing page do projeto acadêmico **lume** (ESPM · Gestão de Produtos): uma companheira por vídeo, com rosto e voz, para idosos que moram sozinhos.

## Estrutura

- `index.html` — página única, HTML/CSS/JS sem dependências (fontes via Google Fonts).
- `assets/keyvisual.webp` — imagem principal do hero.

## Publicação

O site é servido pelo GitHub Pages a partir deste repositório. Para rodar localmente, basta abrir `index.html` no navegador ou servir a pasta com qualquer servidor estático:

```bash
python3 -m http.server 8000
```
